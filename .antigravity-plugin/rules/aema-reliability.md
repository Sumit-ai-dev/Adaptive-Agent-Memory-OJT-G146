# AEMA Reliability Rules for Antigravity Agents

1. **Check Experiential Memory First**:
   Before embarking on multi-step debugging, research ideation, or architectural migrations, always run `aema_retrieve` to leverage verified experiential knowledge and avoid repeating historical mistakes.

2. **Negative Transfer Awareness**:
   Never trust memories purely based on high semantic similarity. Only trust memories with active, non-quarantined status ($S \ge 0.35$).

3. **Mandatory Outcome Feedback**:
   Every time an experiential solution is recalled and tested in execution, report the real-world outcome via `aema_feedback` so that A-EMA trust scoring can adjust dynamically.
